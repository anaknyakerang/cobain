# 📚 AKA Practice Assistant

A simple learning project developed with AI assistance to help me practice **Analisis Kompleksitas Algoritma (AKA)**, especially in calculating \(T(n)\), understanding summations, counting loop iterations, and determining asymptotic complexity.

## 🎯 Purpose

The main goal of this project is to make solving practice problems faster, easier to understand, and more structured. It helps me work through algorithm analysis exercises step by step and check my answers more efficiently.

## 🤖 AI Disclosure

This project was created with the assistance of AI. AI helps generate practice questions, provide hints, explain solution steps, calculate time complexity, and check my answers.

I use this project as a learning aid to improve my understanding of algorithm analysis, not as a replacement for learning or independent problem-solving. I review the explanations and calculations to help ensure that I understand the reasoning behind each answer.

## 🛠️ What I Practice

- Calculating \(T(n)\) for simple and nested loops.
- Understanding summation notation.
- Counting loop iterations.
- Analyzing linear and logarithmic loops.
- Determining asymptotic complexity, such as \(O(n)\), \(O(n^2)\), and \(O(\log n)\).
- Learning through hints, feedback, and step-by-step explanations.

## 💡 Learning Approach

My approach is to attempt each problem, receive guidance, compare my reasoning with the explanation, and correct my mistakes. The purpose is not only to obtain the final answer faster, but also to understand how that answer is derived.

## ⚠️ Disclaimer

AI-generated answers may contain errors. All explanations and calculations should be reviewed and verified, especially when used for coursework or exam preparation.
